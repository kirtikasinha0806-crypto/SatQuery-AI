## 📌 Executive Summary

**SatQuery AI** is an interactive, geospatial multimodal platform designed to bridge the gap between complex satellite imagery analysis and natural language inquiry. Standard Vision-Language Models (VLMs) frequently hallucinate quantitative metrics, lack spatial awareness of Coordinate Reference Systems (CRS), and struggle with precision Earth Observation (EO) parameters.

SatQuery AI solves this with a **Grounded Dual-Engine Architecture**:
1. **Deterministic Remote Sensing Compute Engine**: Executes direct, client-side pixel-level radiometric calculations, spectral vegetation indices (VARI, GLI, ExG), Land Use / Land Cover (LULC) segmentation, morphometric object detection, and bi-temporal change detection.
2. **Vision-Language Reasoning Pipeline**: Combines raw imagery and computed telemetry to answer user queries using a structured 4-part reasoning format—eliminating hallucinations and enforcing transparent uncertainty boundaries.

## 🚀 Key Features

### 1. 🛡️ 4-Part Grounded Response Structure
Every analytical answer generated by SatQuery AI follows a strict, verifiable structure:
* **📍 Confirmed Metadata**: Extracted directly from GeoTIFF tags or scenario manifests (Sensor platform, CRS/EPSG code, ground sampling distance, acquisition date, bounding box).
* **📊 Computed Analysis**: Real pixel-derived figures (surface area in km², percentage breakdown, target counts, index means).
* **🧠 AI Visual Interpretation**: Contextual reasoning explaining physical patterns, spatial relationships, and geographic significance.
* **⚠️ Uncertain / Not Available**: Explicit guardrails stating what cannot be derived (e.g., subsurface data, cloud-shadowed ambiguity, exact bathymetry, or unobservable socioeconomic attributes).

### 2. 🔬 Deterministic Remote Sensing Algorithms (`remoteSensingEngine.js`)
* **Spectral Indices**:
  * **VARI** (Visible Atmospherically Resistant Index): $(G - R) / (G + R - B)$
  * **GLI** (Green Leaf Index): $(2G - R - B) / (2G + R + B)$
  * **ExG** (Excess Green): $(2G - R - B) / 255$
* **LULC Segmentation**: 6-class radiometric classification mapping Water Bodies, Dense Canopy, Cropland/Vegetation, Urban/Built-Up, Barren Soil, and Burn Scars.
* **Salient Object Detection**: High-contrast contour extraction and morphological filtering for maritime vessels, building complexes, industrial tanks, and vehicles.
* **Bi-Temporal Change Detection**: Pixel delta subtraction across pre/post temporal rasters, computing newly submerged areas, urban expansion, and canopy loss in km².

### 3. 🗺️ True GeoTIFF & Custom Upload Pipeline (`geotiffParser.js`)
* Real client-side parsing of `.tif` / `.tiff` files via `geotiff.js`.
* Automated extraction of `ModelPixelScale`, `ModelTiepoint`, `GeoKeyDirectory`, `ProjectedCSTypeGeoKey` (e.g. UTM Zones), and `GeographicTypeGeoKey` (WGS84).
* Graceful fallback for standard non-georeferenced images (`.png`, `.jpg`, `.webp`), clearly flagging uncalibrated spatial metrics without breaking analysis.

### 4. 🎛️ Interactive EO Workstation Interface
* **Dual-View Split Curtain Slider**: Slide interactively between pre- and post-event imagery to visually verify bi-temporal changes.
* **Pan & Zoom Canvas**: Smooth 0.2× to 8.0× viewport controls with wheel zoom, mouse drag, and fit-to-screen reset.
* **Visual Layer Overlays**: Toggle object bounding boxes with confidence scores, color-coded LULC segmentation masks, and change heatmaps with opacity controls.
* **Telemetry Bar**: Live CRS readout, coordinate tracking, spatial resolution, and raster dimensions.
* **Report Export**: One-click download of comprehensive audit reports in JSON format containing scene metadata, computed statistics, and conversation logs.

### 5. 🔌 Pluggable VLM Provider Support (`vlmProvider.js`)
* **Deterministic RS Grounded Engine**: Runs 100% locally in-browser with zero API keys and zero latency.
* **Google Gemini Integration**: Native support for Gemini 1.5 & 2.0 Flash for enhanced natural language dialogue.
* **OpenAI / Ollama / Custom Endpoints**: Configurable for custom local or cloud vision-language models.

## 🛠️ Installation & Setup

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher

### 1. Clone & Install Dependencies
```bash
git clone <repository-url>
cd Hackathon
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
npm run preview
```

## 🔒 Security & Privacy

* **Zero-Upload Local Processing**: The default deterministic engine processes all image data locally in your browser memory using HTML5 Canvas and TypedArrays.
* **Credential Protection**: When utilizing external VLM providers (e.g. Gemini, OpenAI), API keys are stored solely in your browser's `localStorage` and sent directly to the official provider endpoints over HTTPS.
